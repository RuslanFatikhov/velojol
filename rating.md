# Математика рейтинга велодорожки

Документ описывает текущую формулу из кода проекта. Основной источник: `app/models/bikelane.py`.

## 1. Длина велодорожки

Длина считается из GeoJSON-геометрии велодорожки.

1. Берется массив координат `geometry.coordinates`.
2. Для каждой пары соседних точек считается расстояние по формуле гаверсинуса.
3. Все расстояния суммируются.
4. Итог округляется до 2 знаков после запятой.

Формула гаверсинуса:

```text
R = 6371 км

dLat = radians(lat2 - lat1)
dLon = radians(lon2 - lon1)

a = sin(dLat / 2)^2
  + cos(radians(lat1)) * cos(radians(lat2)) * sin(dLon / 2)^2

c = 2 * atan2(sqrt(a), sqrt(1 - a))

distance = R * c
```

Итог:

```text
length = round(sum(distance_between_each_pair), 2)
```

Если координат меньше двух или геометрия некорректна, длина равна `0`.

## 2. Качество покрытия

Пользователь выбирает качество покрытия вручную:

```text
1 = Ужасно
2 = Плохо
3 = Средне
4 = Хорошо
5 = Отлично
```

Это значение хранится в поле `quality`.

## 3. Итоговый рейтинг качества велодорожки

Итоговый рейтинг качества считается методом `calculate_overall_quality()` и ограничивается диапазоном от `1` до `5`.

### Базовый рейтинг по типу дорожки

```text
separated = 5  Обособленная велодорожка
bollards  = 4  Полоса с боллардами
lane      = 3  Полоса
shared    = 3  Вело-пешеходная дорожка
```

Если тип неизвестен, базовое значение равно `3`.

### Модификаторы

```text
Если есть парковка автомобилей на велодорожке: -2
Если есть разметка: +0.5
Если есть дорожные знаки: +0.5
Если качество покрытия <= 2: -1
Если качество покрытия >= 4: +1
```

### Финальная формула

```text
raw_quality =
    base_quality_by_track_type
    - has_parking_penalty
    + markings_bonus
    + signs_bonus
    + surface_quality_modifier

overall_quality = round(raw_quality)
overall_quality = min(5, max(1, overall_quality))
```

## 4. Цвет качества на карте

Цвет зависит от `quality`, то есть от качества покрытия, а не от `overall_quality`.

```text
1 = #e74c3c  красный
2 = #e67e22  оранжевый
3 = #f39c12  желтый
4 = #2ecc71  зеленый
5 = #27ae60  темно-зеленый
```

Если значение неизвестно, используется `#3498db`.
