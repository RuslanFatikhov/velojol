# Монетизация баллов

Документ описывает текущую систему баллов в проекте. Денежная монетизация, вывод средств или курс обмена баллов на деньги в коде сейчас не реализованы.

## 1. Когда начисляются баллы

Баллы за велодорожку начисляются только после одобрения модератором.

При одобрении вызывается `bikelane.approve(...)`:

```text
status = approved
moderated_at = текущая дата
moderated_by = id модератора
admin_comment = комментарий модератора
```

Если у велодорожки `score == 0`, рассчитываются баллы через `calculate_score()`.

Если велодорожка отклонена, ее баллы сбрасываются:

```text
status = rejected
score = 0
```

## 2. Формула баллов за велодорожку

Источник: `BikeLane.calculate_score()` в `app/models/bikelane.py`.

```text
base_score = 5
photos_count = количество фото
videos_count = количество видео

score = base_score + photos_count + videos_count * 5
```

То есть:

```text
5 баллов за саму одобренную велодорожку
1 балл за каждое фото
5 баллов за 1 ссылку на видео

Примеры:

```text
За 20 символов в <textarea id="description" = 5 баллов
За выбор в track-types - 2 балла
За выбор в quality-rating - 2 балла

0 фото, 0 видео: 5 баллов
3 фото, 0 видео: 8 баллов
2 фото, 1 видео: 12 баллов
4 фото, 1 видео: 20 баллов
```

## 3. Общий счет пользователя

Источник: `User.get_total_score()` в `app/models/user.py`.

```text
total_score =
    сумма score всех approved-велодорожек пользователя
    + manual_score
```

`manual_score` - ручные баллы, которые администратор может выдать пользователю через админку.

## 4. Баллы в турнире

Источник: `_get_tournament_scores()` в `app/routes/public.py`.

В турнире учитываются только велодорожки:

```text
status = approved
user_id не пустой
score > 0
```

Для периода `week` учитываются велодорожки за последние 7 дней.

Для периода `month` учитываются велодорожки за последние 30 дней.

Дата для периода берется так:

```text
если moderated_at есть: moderated_at
если moderated_at нет: created_at
```

Для периода `all` суммируются все одобренные велодорожки. `manual_score` добавляется только для общего рейтинга `all` без фильтра по стране или городу.

## 5. Что не будет реализовано



```text
конвертации баллов в деньги
стоимости одного балла
баланса выплат
истории выплат
заявок на вывод
платежного провайдера
кошельков пользователей
```

Сейчас баллы работают как внутренняя турнирная валюта/очки рейтинга.
